# MakeBoldSpark.Core

Core functionality and foundational components for the MakeBoldSpark platform.

## Overview

MakeBoldSpark.Core provides essential building blocks and interfaces for the MakeBoldSpark ecosystem, including data models, repositories, and service abstractions.

## Features

- Domain models for web content management
- Repository patterns and abstractions
- Service interfaces and utilities
- Configuration and dependency injection support

## Getting Started

Add a reference to MakeBoldSpark.Core in your project to access core functionality.

```csharp
using MakeBoldSpark.Core;
```
