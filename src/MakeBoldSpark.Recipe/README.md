# MakeBoldSpark.Recipe

A recipe package for MakeBoldSpark that provides templates and utilities for building web applications.

## Overview

MakeBoldSpark.Recipe contains reusable patterns and components designed to accelerate web development within the MakeBoldSpark ecosystem.

## Features

- Pre-built templates for common web patterns
- Extension methods for common operations
- Utility classes for web development

## Usage

Reference this package in your project to access recipe components and patterns.

```csharp
using MakeBoldSpark.Recipe;
```
