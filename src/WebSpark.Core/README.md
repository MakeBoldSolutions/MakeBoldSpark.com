# WebSpark.Core

Core functionality and foundational components for the WebSpark platform.

## Overview

WebSpark.Core provides essential building blocks and interfaces for the WebSpark ecosystem, including data models, repositories, and service abstractions.

## Features

- Domain models for web content management
- Repository patterns and abstractions
- Service interfaces and utilities
- Configuration and dependency injection support

## Getting Started

Add a reference to WebSpark.Core in your project to access core functionality.

```csharp
using WebSpark.Core;
```
