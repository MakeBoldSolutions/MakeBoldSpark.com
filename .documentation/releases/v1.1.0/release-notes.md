## Highlights

This release adds a branded CMS administration application for the
MakeBoldSpark content platform. Administrators can manage content, navigation,
reusable content, subscribers, newsletters, and mail settings through a visual
interface rather than direct API calls.

It also establishes a real administrator authentication boundary. Sign-in now
verifies credentials, issues signed tokens, validates signatures on protected
routes, and limits repeated failed sign-in attempts without exposing why a
login failed.

## New Features

### CMS Admin App

The embedded React SPA provides authenticated management for the platform's
eleven CMS resource types, including resource-specific behavior for navigation
trees, immutable newsletter history, and masked sensitive values.

## Breaking Changes

- Protected API routes now require a configured JWT signing key or authority
  and reject unsigned or invalidly signed tokens. Configure `Jwt:SigningKey` or
  `Jwt:Authority` before deployment.

## Upgrade Guide

1. Deploy the API and embedded CMS application together.
2. Configure `Jwt:SigningKey` or `Jwt:Authority` in every environment before
   starting the API.
3. Bootstrap at least one administrator with a securely hashed password before
   attempting CMS sign-in.
